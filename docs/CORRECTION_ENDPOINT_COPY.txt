  not be summed as exclusive costs. work/latest-performance-audit.json.

  it does not authorize dropping native updates or verification.
- C++ call-site audit: after prepare_adjacent, NativeAdjacentRestore uses its

Changes:
- History/direct restore copies that endpoint subset, while preparing the full
  native reader synchronously from the owned immutable archived endpoint.
  No archived pointer survives that call. Generic fixture path retains full copy.
- Preserve all existing copy count/capacity validation, ownership rechecks,
  adjacent structural preflights, source guards, native loading, exact endpoint
  verification, cleanup and round safety. No input delay/prediction limit change.
- Remove duplicate length-sum scan in prepare_reader_from; copy_recorded_from
  still validates every length and total before modifying destination.
- Cache the fixed reset-span plan instead of recomputing/sorting per reset.
