SC6Rollback LivePrediction experimental suite

1. Close SC6 on both PCs. Extract the new ZIP and run Install-Observer.cmd.
2. Launch SC6 and join the FIRST PRIVATE LOBBY. No warmup match.
3. Partner runs Steam-TestSuite.cmd, with Ben's friend code, P2 and consent preset.
   Ben uses Steam-TestSuite-Ben.cmd in Downloads, or Codex starts it.
4. Start both scripts together, wait for the connection, then start the match.
5. Play normally, including neutral inputs and round transitions. No idle period
   or deliberately wrong input is required.
6. Keep games open until reports finish. Collect-RollbackReport.cmd creates the
   ZIP in Downloads. Send both reports to compare corrections and round coverage.
7. Restart BOTH games before another run, or after a contained failure/freeze.

This profile uses a separate authenticated raw-input channel, hold-last prediction,
up to three unconfirmed frames, native snapshot restoration and correction replay.
Only confirmed raw input reaches the native recorder. Round handoff settles pending
corrections before releasing ownership, then requires fresh resources and bilateral
admission for the next round. Native transition/timeout waits are not bypassed.

The existing restoration checks, ownership checks, raw diagnostics and round guards
remain enabled. A transport PASS or update count does not prove prediction worked.
Look at the -continuous.txt and -continuous-events.csv reports for admissions,
corrections, replayed frames, waits, restoration failures and round retirement.
The bounded experiment stops at the capture limit or an unsafe failure; it is not
an automatic ranked-play feature. First live validation of this integration is pending.
